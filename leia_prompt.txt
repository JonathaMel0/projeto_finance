# Projeto: Aplicação pessoal de controle financeiro integrada ao Telegram e Google Sheets

## 1. Objetivo

Quero desenvolver uma aplicação pessoal de controle financeiro com foco em:

* simplicidade;
* baixo custo;
* facilidade de manutenção;
* possibilidade de hospedar gratuitamente ou com custo próximo de zero;
* lançamento de receitas e despesas através do Telegram;
* armazenamento dos dados no Google Sheets;
* dashboard web responsivo para computador e celular;
* possibilidade de editar e excluir lançamentos;
* relatórios mensais;
* acompanhamento de orçamento;
* sugestões de limite de gastos e organização financeira.

É um projeto pessoal, portanto não quero uma arquitetura empresarial complexa.

**Não quero gastar dinheiro com APIs de LLM inicialmente.**

A aplicação deve funcionar prioritariamente através de regras e processamento determinístico. Se futuramente for interessante adicionar uma LLM, a arquitetura deve permitir isso sem precisar reescrever todo o sistema.

---

# 2. Stack desejada

Priorizar tecnologias gratuitas ou de baixo custo.

Sugestão inicial:

### Frontend

* Next.js
* React
* TypeScript
* Tailwind CSS
* Recharts ou biblioteca equivalente para gráficos
* Responsivo para desktop e celular
* Pode ser hospedado na Vercel

### Backend

Pode ser implementado dentro do próprio Next.js utilizando API Routes / Route Handlers.

Não quero criar um servidor separado inicialmente.

### Banco de dados

Google Sheets.

Utilizar Google Apps Script ou Google Sheets API para leitura e escrita.

A escolha entre Apps Script e Google Sheets API deve considerar:

* simplicidade;
* custo;
* facilidade de manutenção;
* autenticação;
* limites de uso;
* segurança mínima necessária.

Se Google Apps Script for suficiente, prefira essa solução.

### Código

* GitHub
* Git
* TypeScript
* `.env` para configurações e credenciais
* README completo

### Hospedagem

Preferência:

* Vercel para aplicação web/API;
* Google Sheets para armazenamento;
* Google Apps Script quando fizer sentido;
* Telegram Bot API para comunicação.

O objetivo é manter o custo mensal próximo de R$0.

Quero criar um bot no Telegram que possa ser utilizado em uma conversa ou grupo.

Exemplo:

Usuário envia:

`padaria 54,90`

O sistema deve interpretar:

* descrição: Padaria
* valor: R$ 54,90
* tipo: despesa
* categoria: Alimentação
* data: data atual
* horário: horário atual
* moeda: BRL

* descrição: Salário Valid

* tipo: entrada
* categoria: Salário

* descrição: Pix João

# 50. Prioridade

Priorize nesta ordem:

1. simplicidade;
2. baixo custo;
3. funcionamento;
4. facilidade de manutenção;
5. boa experiência;
6. segurança básica;
7. escalabilidade futura.

Não quero transformar um projeto pessoal em uma arquitetura complexa.

Antes de começar a implementação, analise este projeto criticamente e proponha alterações que reduzam custo, complexidade ou pontos de falha.

Depois disso, apresente a arquitetura final recomendada e comece a implementação pela Fase 1.
